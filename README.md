# Sistema de Gestión - Taller Textil "Vasco"

## 📝 Descripción del Proyecto
Este proyecto consiste en la digitalización de los procesos de producción de un taller de confección textil. El objetivo es resolver problemas críticos de inventario, seguimiento de pedidos, control de productividad y gestión financiera.

## 🎯 Alineación con ODS 9
Este sistema contribuye al **Objetivo de Desarrollo Sostenible 9: Industria, Innovación e Infraestructura**, al promover la modernización tecnológica de pequeñas industrias locales para aumentar su eficiencia y competitividad.

## 🛠️ Gestión del Proyecto
La gestión de requerimientos se realizó mediante **Historias de Usuario** validadas bajo el estándar **INVEST**, las cuales pueden visualizarse en la pestaña de **Projects** de este repositorio.
